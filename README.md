# Точка и клик

Каталог **point-and-click квестов** — приключенческих игр, в которых историю
двигают внимательность и курсор, а не скорость реакции.

## Для кого этот проект

Для новичков в жанре, которым нужен квест на вечер, и для опытных игроков,
которые ищут что-то поспокойнее экшена. В каталоге собраны короткие комедии
и длинные хорроры: в каждой карточке указано примерное время прохождения,
поэтому игру легко подобрать под свободный вечер.

## Основные блоки страницы

- **Шапка** — название проекта и навигация (Каталог / Как пользоваться / О проекте).
- **Главный блок** — заголовок с описанием задачи проекта и три факта о каталоге.
- **Поиск по каталогу** — форма с текстовым полем, двумя выпадающими списками,
  числовым полем и чекбоксом. Сейчас форма только собирает условия,
  фильтрация появится в следующих лабораторных работах.
- **Каталог** — шесть карточек-`<article>`; у каждой есть иллюстрация, название,
  короткое описание и список свойств: жанр, год выпуска, сложность загадок,
  примерное время прохождения.
- **Как пользоваться каталогом** — три шага работы с подборкой.
- **О проекте** — для кого сделан каталог, что планируется дальше, какие
  технологии использованы.
- **Подвал** — название проекта, контакт и ссылка «Наверх».

## Как открыть

1. Склонируйте репозиторий или распакуйте архив.
2. Откройте `index.html` в любом современном браузере — двойным щелчком
   по файлу или через «Открыть файл».

Дополнительных установок не требуется: страница статическая, JavaScript
не используется.

## Технологии и раскладка

- **HTML5**: семантические элементы `header`, `nav`, `main`, `section`,
  `article`, `figure`, `footer`.
- **CSS3**: стили лежат в отдельном файле `styles/main.css`.
- **CSS Grid** — сетка карточек `.cards` (1 → 2 → 3 колонки), поля формы
  `.filter-form__fields`, список шагов `.steps` и список фактов `.facts`.
- **Flexbox** — шапка, навигация, кнопки формы и подвал.
- **Адаптивность**: контрольные точки 600, 700, 768, 1000 и 1100 px;
  проверено на ширинах 360, 768 и 1280 px.

## Изображения

Все иллюстрации карточек — собственные SVG-файлы проекта, лежат в
`assets/images/`:

| Файл | Карточка |
| --- | --- |
| `lighthouse.svg` | Пропавший маяк |
| `mansion.svg` | Пиксельный особняк |
| `cafe.svg` | Кофейня на Второй улице |
| `station.svg` | Станция «Юпитер-9» |
| `library.svg` | Тайна старой библиотеки |
| `tram.svg` | Полночный трамвай |

Внешние источники не используются, поэтому страница не ломается,
если сторонние сервисы недоступны.

- рабочий поиск и фильтрация по параметрам формы;
- отдельная страница для каждого квеста;
- загрузка данных с сервера и хранение каталога в базе.
